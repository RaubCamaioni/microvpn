[install WireGuard]
  1. Get the app from wireguard.com/install.
  2. Windows, macOS, Linux: [download] a profile's config, then in the app Add Tunnel → Import tunnel(s) from file.
  3. Android, iOS: in the app + → Scan from QR code and point it at the profile's [QR].
  4. iPhone, iPad, Mac: [add to WireGuard] saves a profile that installs through Settings.
  5. Activate the tunnel. Members reach each other on their 10.x.y.z addresses. When someone joins later, import the config again: it only lists the members present when it was made.
[use your own key]
  1. On the machine that will use the tunnel, install wireguard-tools (apt install wireguard-tools, brew install wireguard-tools, or the WireGuard app, which ships wg).
  2. Make the key pair there. The private half stays in private.key; the command prints the public half: 
    wg genkey | tee private.key | wg pubkey
  3. Paste the printed public key into the new-profile form below. Leave it empty instead and this browser makes the key, which never leaves this device.
  4. In that profile's config, replace PrivateKey = __PRIVATE_KEY__ with the contents of private.key, then import it. (WireGuard for Windows: Add empty tunnel makes a key pair too; copy its public key here and paste the rest of the config into that tunnel.)
