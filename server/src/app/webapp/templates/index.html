new room

how it works

  1. Create a room and share its link. Whoever creates it is the admin: every other device that asks to join waits until the admin's browser accepts it, seeing its alias, IP address and approximate location.
  2. Each device makes its own WireGuard key, in the browser or with wg genkey, and sends only the public key.
  3. Download the config or scan the QR code with the WireGuard app. Members get 10.x.y.z addresses and talk to each other through the relay.
  4. When the time is up the room ends and nothing about it is kept.

what the server sees

The server never holds a private key and is never a WireGuard peer. It forwards encrypted UDP between members and cannot read it. It does see room and device names, public keys, members' public IP addresses, and the size and timing of packets.
